[ THE MOTIVE ]

Models stop learning the day training ends.

Think of an LLM like a brilliant student who memorized last year’s textbook from cover to cover. When you ask them a question, they answer with total confidence. But if yesterday’s pricing was raised, a framework released a major version, or an executive stepped down, they have no way of knowing.

Local and offline models are private and cheap to run, while retraining frontier models costs millions. StaleCheck keeps the cheap local model as the reasoning brain and adds an automated, live fact-checking layer over every volatile output.

Facts come from live sources. Models only reason.

[ BIFROST GATEWAY ] Every model call goes through one gateway: unified routing, provider failover, and metrics.

Memory Cache (SQLite)

Repeat claims skip the live search entirely. Time-to-live is tailored per category: pricing: 6h, version: 12h, leadership: 24h, law: 72h, other: 24h.

Early Exit Optimization

If the Extract node finds no claims that can expire (e.g. math theorems, timeless history), the pipeline halts immediately with overall: null. No wasted tokens.

[ HOW THE SCORE WORKS ]

0 to 100. Calibrated for real-world risk.

Scores reflect verifiable freshness, not subjective confidence.

0–29 · STALE
30–69 · NEEDS CONTEXT
70–100 · FRESH

No evidence is never Fresh

If web search returns conflicting or unauthoritative results, the claim is marked Unverifiable and capped at Needs Context (50 max). It is never assumed fresh.

Publication recency decay

Undated pages are penalized and capped at 85. Older sources incur progressive score deductions to prioritize recent developments.

Independent judge model

The judge model is strictly configured from a different provider than the analyst model to eliminate self-grading bias.

Empty claims yield null

Answers with no time-sensitive claims report an overall score of null (—) rather than a false 100% perfection rating.

How Tavily contributes

Tavily is the sole source of factual truth in StaleCheck. It performs depth-first live web search, normalizes publication timestamps for recency scoring, deduplicates domains, and provides verified source URLs so every claim is anchored in live reality.

How Bifrost contributes

Bifrost by Maxim AI serves as the universal model gateway. It unifies OpenAI, Anthropic, and open-source models under one endpoint, routes independent judging across separate providers, handles virtual-key failovers, and provides observability.

[ HONEST LIMITS ]

What StaleCheck cannot do.

Engineering trade-offs and transparent operational boundaries.

The judge is also an LLM

While grounded by evidence text, language models can occasionally misread nuanced domain jargon. We display full reasoning strings so you can review decisions.

Search quality bounds accuracy

If web search retrieves low-relevance or conflicting articles, the pipeline marks the claim Unverifiable rather than inventing facts.

Undated pages are harder to judge

Websites that omit publication headers cannot be definitively timestamped, capping maximum freshness confidence at 85 points.

Model calls add latency

Running extraction, live search, multi-model analysis, and judging sequentially takes between 4 and 15 seconds per audit.
